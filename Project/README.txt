КОМАНДА ДЛЯ ЗАПУСКА:
-------------------
1. Установите необходимые библиотеки:
   pip install openpyxl

2. Запустите консольное приложение:
   python main.py

3. Откройте веб-интерфейс в браузере:
   index.html

ОПИСАНИЕ ПРОГРАММЫ:
------------------
Это полноценное приложение для отслеживания вакансий и управления откликами на работу.
Программа позволяет парсить вакансии с hh.ru, фильтровать их по зарплате, городу, опыту
и ключевым словам. Реализован трекер откликов с системой статусов (отправлен, просмотрен,
собеседование, отказ, оффер) и подсчётом дней ожидания ответа. Встроенная аналитика
показывает средние зарплаты по специальностям, топ работодателей и востребованные навыки.
Данные сохраняются в JSON между запусками, есть экспорт отчётов в Excel с форматированием.
Веб-интерфейс предоставляет удобный доступ к ленте вакансий, Kanban-доске откликов и
панели аналитики с интерактивными таблицами и фильтрацией.

ИСПОЛЬЗОВАННЫЕ ТЕХНОЛОГИИ:
-------------------------
• ООП: классы Vacancy, Application, JobTracker, JobParser, Analytics с наследованием
• Файлы: чтение/запись JSON и CSV с обработкой исключений
• Модули: пакет app/ с __init__.py и импортами между модулями
• Lambda: filter(), map(), sorted() для обработки данных (более 3 применений)
• Исключения: try/except в критичных местах (работа с файлами, парсинг)
• Datetime: работа с датами, вычисление разницы, isoformat()
• Frozenset: VALID_STATUSES, VALID_EMPLOYMENT_TYPES, VALID_EXPERIENCE_LEVELS
• Openpyxl: экспорт в Excel с жирными заголовками и форматированием
• Парсинг: urllib для API hh.ru с проверкой robots.txt
• Консольное меню: цикл while True с 10 пунктами

ФУНКЦИОНАЛЬНОСТЬ:
----------------
1. Просмотр всех вакансий с сортировкой по зарплате
2. Фильтрация вакансий (зарплата, город, опыт, ключевые слова)
3. Парсинг новых вакансий с hh.ru (с fallback на тестовые данные)
4. Подача откликов на вакансии
5. Просмотр откликов с группировкой по статусам
6. Обновление статуса отклика (с причинами для отказа)
7. Аналитика рынка (статистика, топ работодателей, навыки)
8. Экспорт данных в Excel (3 листа: вакансии, отклики, аналитика)
9. Сохранение данных в JSON
10. Выход с автосохранением
